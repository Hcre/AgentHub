### 3. 真实修复点

**`src/backend/app/api/routers/sessions.py:87-122`**

```python
@router.post("/api/messages/{message_id}/pin", status_code=204)
async def pin_message(
    message_id: UUID,
    session_id: UUID = Query(...),
    current_user: User = Depends(get_current_user_required),  # <-- 401 路径
    db: AsyncSession = Depends(get_db),
) -> Response:
    msg = await message_repo.get_by_id(db, message_id)
    if not msg:
        raise HTTPException(404, "Message not found")
    if msg.session_id != session_id:
        raise HTTPException(422, "Session mismatch")
    if msg.user_id != current_user.id:
        raise HTTPException(403, "Not message owner")
    # 4. Pin: 实际副作用
    await message_repo.pin(db, message_id)
    return Response(status_code=204)
```

5 路径映射:
- Path 1 (204) -> `get_current_user_required` + `msg.user_id == current_user.id` 通过
- Path 2 (403) -> owner 校验失败
- Path 3 (422) -> session_id 校验失败
- Path 4 (404) -> message_id 不存在
- Path 5 (401) -> `get_current_user_required` 抛 AuthRequiredError
