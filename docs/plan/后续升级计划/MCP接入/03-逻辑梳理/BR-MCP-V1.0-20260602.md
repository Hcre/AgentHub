# 业务规则表（BR）— AgentHub MCP 接入 V1.0

> **项目代号**：MCP

## R-001 [MCP 命名唯一性]

- **描述**: MCP name 全局唯一，命名遵循 kebab-case
- **适用范围**: F-001, F-002, F-018
- **优先级**: 高
- **冲突处理**: 重复时拒绝 + 提示
- **来源标注**: [PRD:F-001, F-018]

## R-002 [MCP 安装幂等性]

- **描述**: 同一 user + 同一 mcp 重复安装返回同一 instance
- **适用范围**: F-004
- **优先级**: 高
- **冲突处理**: 已存在则返回已有 instance_id
- **来源标注**: [PRD:F-004 验收③]

## R-003 [MCP 版本管理]

- **描述**: 同一 mcp_name 最多 50 历史版本，超出 LRU 清理
- **适用范围**: F-008
- **优先级**: 中
- **冲突处理**: pinned 版本不被 LRU 清理
- **来源标注**: [PRD:F-008] + [调研报告:S-060]

## R-004 [semver 规范]

- **描述**: 版本号遵循 semver (MAJOR.MINOR.PATCH)
- **适用范围**: F-008
- **优先级**: 中
- **冲突处理**: CVE 紧急更新允许绕过主版本号提升
- **来源标注**: [PRD:F-008] + [调研报告:S-059]

## R-005 [绑定关系唯一性]

- **描述**: 同一 agent + 同一 instance 重复绑定幂等返回
- **适用范围**: F-009, F-011
- **优先级**: 高
- **冲突处理**: 已存在则返回已有 binding_id
- **来源标注**: [PRD:F-009]

## R-006 [工具名长度硬限制]

- **描述**: 工具名 ≤ 64 字符（Anthropic/OpenAI API 限制）
- **适用范围**: F-009, F-011
- **优先级**: 高
- **冲突处理**: 超长自动截断（server_slug 32 + tool_name 28 + 6 字符 hash 后缀）
- **来源标注**: [调研报告:S-005, S-035]

## R-007 [MCP 注入 graceful degradation]

- **描述**: 注入失败时 Agent 仍可启动，记录 warning 日志
- **适用范围**: F-012
- **优先级**: 中
- **冲突处理**: 注入超时 1s 内不阻塞 Agent 启动
- **来源标注**: [PRD:F-012 验收③]

## R-008 [WebSocket 投递 99.5% SLO]

- **描述**: 工具调用事件端到端投递成功率 ≥ 99.5%
- **适用范围**: F-014
- **优先级**: 高
- **冲突处理**: 失败重发 3 次 + 断线 30s 重连
- **来源标注**: [PRD:S-05, F-014] + [调研报告:S-054, S-055]

## R-009 [WebSocket 断线重连 30s]

- **描述**: 断线 30s 内自动重连并重发未 ack 事件
- **适用范围**: F-014
- **优先级**: 高
- **冲突处理**: EventSource 自动重连 + 后端兜底
- **来源标注**: [PRD:NF-05, F-014] + [调研报告:S-055]

## R-010 [工具调用超时 30s]

- **描述**: 单次 tool_call 默认 30s 超时
- **适用范围**: F-016
- **优先级**: 中
- **冲突处理**: 取消请求 2s 内到达 Runtime
- **来源标注**: [PRD:F-016 验收①]

## R-011 [沙箱资源限制]

- **描述**: dry-run 沙箱 CPU ≤ 1 核、Mem ≤ 512MB、网络默认隔离
- **适用范围**: F-021
- **优先级**: 高
- **冲突处理**: 超限返回 error_code=`RESOURCE_EXCEEDED`
- **来源标注**: [PRD:F-021 验收②] + [调研报告:S-025]

## R-012 [沙箱命令构造安全]

- **描述**: subprocess 必须 list 形式，禁止 shell=True
- **适用范围**: F-021
- **优先级**: 高（安全）
- **冲突处理**: 字符串拼接检测拒绝（CVE-2025-53372 防逃逸）
- **来源标注**: [调研报告:S-026, RSK-07]

## R-013 [NPROC 限制 cgroup v2]

- **描述**: Linux 下进程数限制用 cgroup v2 `pids.max` 而非 setrlimit
- **适用范围**: F-021
- **优先级**: 高
- **冲突处理**: setrlimit(RLIMIT_NPROC) 会影响父进程，不可用
- **来源标注**: [调研报告:S-025, RSK-04]

## R-014 [dry-run 误报率 MVP 10%]

- **描述**: dry-run 误报率 MVP 接受 10%，3 个月内优化至 2%
- **适用范围**: F-021
- **优先级**: 中
- **冲突处理**: 通过 Semgrep Assistant + 可达性分析优化
- **来源标注**: [调研报告:S-058] + [SA推断:依据 — V1.2 调研 R-008 业界基线 15%]

## R-015 [SSRF 防护多层]

- **描述**: URL 解析用 yarl.URL；DNS 固定 + 重定向验证
- **适用范围**: F-019
- **优先级**: 高（安全）
- **冲突处理**: urllib.parse 不安全，必须替换 [调研报告:S-032, CVE-2022-0391]
- **来源标注**: [调研报告:S-032, S-052, RSK-02]

## R-016 [IPv6 链路本地禁用]

- **描述**: 私网/loopback/fe80::/10 访问拒绝
- **适用范围**: F-019
- **优先级**: 高（安全）
- **冲突处理**: 访问触发 SSRF 告警
- **来源标注**: [调研报告:S-033]

## R-017 [权限显式同意]

- **描述**: MCP 权限变更需 R-03 再次同意（immutable consent）
- **适用范围**: F-025
- **优先级**: 高
- **冲突处理**: 未授权访问返回 error_code=`PERMISSION_DENIED`
- **来源标注**: [PRD:F-025] + [调研报告:S-064]

## R-018 [审计日志不可变]

- **描述**: 审计日志 INSERT ONLY，REVOKE UPDATE/DELETE
- **适用范围**: F-017
- **优先级**: 高

## R-019 [重试 1 次 + 2s 间隔]

## R-020 [告警去重 5min 窗口]

## 规则冲突检测

| 规则对 | 冲突描述 | 仲裁 |
|---|---|---|
| R-003 vs R-004 | LRU 清理 vs CVE 紧急更新 | CVE 紧急 patch 标记 `is_critical_patch=true`，避开 LRU 清理 |
| R-006 vs R-009 | 工具名 64 字符 vs 断线重连 30s | 无冲突（不同维度） |
| R-011 vs R-012 | 资源限制 vs 命令构造 | 协同：CPU/Mem/进程数 + 命令 list 形式 |
| R-014 vs R-011 | 误报率 vs 资源限制 | 协同：误报率高时人工复核兜底 |
| R-017 vs R-013 | 权限 vs NPROC 限制 | 协同：权限声明包含 pids_max |

[SA洞察#10] R-014 dry-run 误报率 10% 是 MVP 妥协，3 个月内必须优化至 2%（调研报告 S-058 路径）。若 3 个月内未达成，需触发 PRD 升级流程（V1.4）。

**阶梯退出检查**: ①规则间无循环依赖: 是 ②冲突均有仲裁: 是 ③D2: 95%
