## EX-001 ~ EX-067 异常场景定义（按 BP 顺序）

### BP-001 MCP 市场首页

- **EX-001** [输入异常] 路由参数非法 → 400 + 默认 zh-CN
- **EX-002** [资源异常] Redis 缓存雪崩 → 走 DB 直查 + 告警
- **EX-003** [通信异常] CDN 边缘节点超时 → 走最近可用节点
- **EX-004** [状态异常] 推荐位配置冲突（position 重复）→ 拒绝 + 提示
- **EX-005** [逻辑异常] R-01 配置推荐位的 MCP 已被下架 → 拒绝并提示
- 来源: [PRD:F-001] + [调研报告:S-053]

### BP-002 列表/搜索/筛选

- **EX-006** [输入异常] 搜索关键字 > 100 字符 → 截断
- **EX-007** [输入异常] 筛选条件非法组合 → 422
- **EX-008** [资源异常] PostgreSQL 全文索引不可用 → 降级 LIKE 查询 + 告警
