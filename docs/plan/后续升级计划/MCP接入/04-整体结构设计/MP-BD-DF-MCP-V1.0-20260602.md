# 第二部分：系统边界定义（BD）

|---|---|---|---|---|---|
| B-001 | 输入 | R-03 终端用户通过 HTTPS 浏览器访问 MCP 市场/详情/IM 会话 | M-001/M-002/M-018 | HTML + JSON | TLS1.3 + CSRF token + 用户登录态校验 [PRD:F-003 验收③] |
| B-002 | 输入 | R-02 开发者通过 Web 表单提交 MCP 创建/版本/权限/可见性配置 | M-011/M-005/M-014/M-015 | JSON/YAML | TLS + 角色权限校验 + Schema 校验 [BP-022] |
| B-003 | 输入 | R-01 管理员配置推荐位/告警阈值/分类标签策略 | M-001/M-017/M-004 | JSON | TLS + 管理员双因子 + 操作审计 |
| B-004 | 输入/输出 | Runtime（ClaudeCode/OpenCode/PiAgent）通过 WSS 上报 tool_call 事件 + 接收 ack | M-008/M-007 | WSS + JSON-RPC（MCP 2025-06-18） | JWT agent_id 鉴权 + 5s ack 重发 [PRD:F-014 + S-054] |
| B-005 | 输出 | 第三方 MCP（stdio 子进程 / sse/http 远端）通过沙箱受控调用 | M-013/M-007 | stdio + Streamable HTTP | 沙箱隔离 + 网络白名单（egress allowlist）+ DNS pinning [S-033/S-052] |
| B-006 | 不处理 | Runtime 自身的 LLM 模型推理与上下文管理（属于 Runtime 内部，平台只做工具调用桥接） | — | — | 平台明确不持有 LLM API Key 路由（通过 Runtime 自身配置） |

## 核心数据流：MCP 安装 → 绑定 → 工具调用全链路

```
[B-001 R-03 用户点击安装]
        │ POST /mcp/install
        ▼
┌──────────────────────────────────────────────────────────┐
│ M-002 安装管理                                            │
│  1. M-022 acquire lock(user_id, mcp_id)                  │ ← 修复 CE-001
│  2. INSERT DE-005 (status=installing)                    │
│  3. publish('mcp.installation.start') to M-021           │
└──────────────────────────────────────────────────────────┘
        │ 异步                                  │ 异常路径
        ▼                                       ▼
┌──────────────────────────────────────────┐   ┌─────────────────────────┐
│ M-013 沙箱执行                            │   │ M-Error / M-020         │
│  - dry-run 启动 (Docker/cgroup_v2)       │   │ EX-014~018:             │
│  - 30s 超时硬限制                         │   │  网络异常/依赖缺失      │
│  - DE-010/011 写入                       │   │  → error_code           │
└──────────────────────────────────────────┘   │  → 通知 R-03            │
        │ 成功                                    └─────────────────────────┘
        ▼
UPDATE DE-005 status=ready, publish('mcp.installation.ready')
        │
        ▼
┌──────────────────────────────────────────────────────────┐
│ M-006 Agent 绑定（用户后续操作）                          │
│  - 校验 tools ≤ 64 字符（M-012）+ 截断 + 唯一性 [CE-003] │
│  - M-022 共享 instance_id 锁 [CE-014]                    │
│  - INSERT DE-006                                          │
│  - publish('mcp.binding.changed')                         │
└──────────────────────────────────────────────────────────┘
        │
        ▼
┌──────────────────────────────────────────────────────────┐
│ M-007 Adapter 注入（订阅 mcp.binding.changed）           │
│  - 通过 AdapterPlugin SPI 翻译 schema                     │
│  - subprocess.run(list 形式, shell=False) [R-012]        │
│  - 注入超时 1s → graceful degradation [PRD:F-012 验收③] │
│  - Runtime 健康检查 30s 周期 [CE-004]                    │
└──────────────────────────────────────────────────────────┘
        │ 异常路径
        ▼
publish('mcp.runtime.unhealthy') → M-008 阻断路由 + M-017 告警
```

## 工具调用事件流（含异常 + 审计去重）

```
[B-004 Runtime 上报 tool_call]
        │ WSS event
        ▼
┌──────────────────────────────────────────────────────────┐
│ M-008 WS 网关                                             │
│  - 鉴权 (agent_id + JWT)                                 │
│  - 解析 schema + 路由表查询（M-006）                      │
│  - 令牌桶限流 100 req/s [CE-005]                          │
│  - publish('mcp.tool_call.event') → M-021                │
│  - 5s 未 ack → 重发 ≤3 次 [S-054]                        │
│  - 断线 30s → 自动重连 [S-055]                           │
└──────────────────────────────────────────────────────────┘
        │ 并发分发
   ┌────┼────┐
   ▼    ▼    ▼
┌─────┐ ┌─────┐ ┌─────┐
│M-009│ │M-010│ │M-016│
│编排 │ │审计 │ │用量 │
└─────┘ └─────┘ └─────┘
   │      │       │
   │      │ event_id 去重 [CE-013]
   │      │ INSERT-ONLY (REVOKE UPDATE/DELETE) [R-018]
   │      ▼
   │  DE-009 → 90d 后 S3 归档
   │
   │ 异常路径：tool_call 失败
   ▼
┌──────────────────────────────────────────────────────────┐
│ M-009 工具调用编排                                        │
│  - cancel_token 检查 [CE-011]                            │
│  - 重试 1 次 / 2s 间隔 [R-019]                           │
│  - 失败 → 降级提示 → publish('mcp.tool_call.failed')     │
└──────────────────────────────────────────────────────────┘
        │
        ▼ 错误率 > 30%（5min 窗口）
┌──────────────────────────────────────────────────────────┐
│ M-017 告警（Prometheus AlertManager）                     │
│  - dedup_key 含 minute_bucket [CE-012]                   │
│  - 5min 去重窗口                                          │
│  - publish('mcp.alert.triggered') → M-020 推送           │
└──────────────────────────────────────────────────────────┘
```
