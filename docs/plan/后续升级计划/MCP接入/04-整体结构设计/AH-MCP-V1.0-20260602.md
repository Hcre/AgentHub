## 三、TD 洞察注入记录（R11 满足，3 轮共 ≥3 条）

| 轮次 | 洞察类型 | 洞察内容 |
|---|---|---|
| 轮1 | 主题耦合 | 「市场展示」与「安装管理」两个主题强耦合（市场点击直接触发安装 BP-004），但其他主题间耦合度低 → 适合分层主题骨架，避免合并为单一巨模块 |
| 轮2 | 模块循环依赖+并发风险 | SA 提交的 BP-005（卸载）+ BP-009（绑定）+ BP-004（安装）共享 `instance_id` 数据维度，14 反例中 CE-001/014 均指向并发竞态 → 必须引入 M-022 分布式锁（ADR-003），否则数据库唯一约束兜底将产生不可控的 race condition 日志噪音 |
| 轮3 | 异常流向缺失+扩展瓶颈 | CE-004 Runtime 注入后立即崩溃在 SA 现有流向中无对应处理路径；现有 M-007 若不暴露 SPI，将每接入一个 Runtime（含未来 Cursor/Cline 等）都需修改核心代码 → 提出 ADR-004 SPI 插件化 + `mcp.runtime.unhealthy` 事件（M-021），补全异常流向 |
