# 演进路线图 ER-MCP-V1.0-20260602

> **范围**：V1.0 → V3.0 三阶段演进（[灵魂 R25] 含回滚策略）

## V2.0 — Codex/Trae Runtime 接入（触发：BR-035 季度复查命中 2026 Q3 末）

```
[演进阶段] V2.0
[触发条件] Codex CLI / Trae IDE 官方 release 支持 MCP（Q-04/NB-01）
[新增模块] M-C10 RuntimeAdapter-Codex (复用 M-A03 Webhook 模式)
[废弃模块] 无
[迁移策略] 灰度：5% workspace → 25% → 100%；RuntimeInterface 抽象层（L2 port 模式）
[回滚策略] 灰度比例回退至 0%；保留 M-C10 旧代码冷存 90d
[风险等级] 中
[来源标注] [SA:BR-035/NB-01 + CE-018 + 灵魂 D6 扩展点验收 5/5]
```

## V2.1 — 工具按需加载（触发：BR-006 32 工具边界接近瓶颈）

```
[演进阶段] V2.1
[触发条件] 单 workspace 绑定 MCP 数 P95 ≥ 24（接近 32 上限）；或 CE-007 工具搜索超时率 > 5%
[新增模块] M-B06 工具元数据缓存（metadata-only, schema 按需）+ M-D04 Schema-CDN
[废弃模块] 无
[迁移策略] 蓝绿：原全量加载 vs 按需加载并行 7d；指标对比后切换
[回滚策略] 蓝绿流量切回；按需加载可降级为全量（5min 内）
[风险等级] 低
[来源标注] [SA:BR-006 + CE-007 + 调研 A-02 MCPCrawler]
```

## V3.0 — 多区域/多租户（触发：客户需求 ≥ 3 个区域或 ≥ 500 workspace）

```
[演进阶段] V3.0
[触发条件] 客户合约含跨区域；workspace 总数 ≥ 500；合规要求数据驻留
[新增模块] M-B07 Region-Router (地理路由) + M-D05 Global-Registry (跨区元数据) + M-A05 API-Gateway-Region
[废弃模块] M-A01 单区域 API Gateway (被 M-A05 取代)
[迁移策略] 双写：原单区 + 新跨区；数据校验一致后切读
[回滚策略] 双写停止；流量切回单区；数据由 Global-Registry 异步回灌
[风险等级] 高
[来源标注] [TD推断:基于物理视图 6,400 进程/1.6TB 内存容量约束推导]
```
