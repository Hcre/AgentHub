## 选择理由

主方案总分 5.78 vs 备选 4.55，差值 1.23（满分 7），按 4.11 规则（差值 ≥ 5 才需双方案标注），实际差值不大。**两者各有优劣**：

- **主方案更适合**：V1.0 MVP 阶段，单团队快速交付，workspace 规模 < 200
- **备选方案更适合**：V3.0+ 阶段，workspace 规模 > 500，需独立扩进程池 Operator

**最终选择**：V1.0 采用主方案；V3.0 演进路径包含从主方案到微服务的迁移。

**关键决策**：4 个微服务候选（沙箱/K4/SSRF+ACL/MCP创建）耦合紧密（同一请求链），强行拆分引入分布式事务得不偿失；通过进程池隔离 workspace 已满足横向扩展需求。详见 ADR-001。
