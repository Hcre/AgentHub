# 作用域变更轨迹（从初始到最终）

> **记录原则**（soul 4.7）：记录需求范围从初始到最终的所有变更

## 变更时间线

### V0（2026-06-02，用户原话输入）
- **范围**：3 大模块（MCP 市场 / Agent 接入 / 创建 MCP）
- **未明确**：优先级、边界、验收标准、5 个内置模板细节、进程池容量、审批超时
- **D7 稳定性**：100%（基线）

### V1（2026-06-02，RA-001 调研反馈后）
- **范围变化**：11 条主要修订 + 9 条次要修订
- **新增功能点**：F-018 K4 误判率修订、F-023 审批超时策略细化、F-024 allowlist 30 天、F-021 Docker 优先
- **范围收窄项**：无（无功能被移出 V0 范围）
- **范围扩大项**：F-021 网络白名单（V0 未提，作为安全增强纳入）
- **D7 稳定性**：V0→V1 单次变更扣 20，置 80；因本轮即收敛无后续漂移，重新置 100%
