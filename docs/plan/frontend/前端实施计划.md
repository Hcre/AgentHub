# AgentHub 前端实施计划 v1

> 版本：v1.0 | 日期：2026-05-23 | 基准确认：选用 v0（AgentHub-v0.html）作为 UI/UX 参考

---

## 一、现状总结

**已有基础设施（src/frontend/ 目录）：**
- Vite + React 18 + TypeScript 脚手架
- Zustand 状态管理（agentStore、chatStore）
- 基本组件：Sidebar、ChatView、MessageBubble、MessageInput、MessageList、SessionList、StreamingText
- API 层：client.ts（fetch 封装）、agents.ts、sessions.ts
- WebSocket hook（useWebSocket.ts）
- 类型定义：Agent、Session、ChatMessage、StreamEvent
- 基本 CSS（飞书蓝风格，~280 行）
- 已有前端 package.json（react 18, zustand 5, vite 6, typescript 5）

**后端已就绪（src/backend/ 目录）：**
- FastAPI 项目，pyproject.toml
- Alembic 数据库迁移
- Dockerfile + Docker Compose（PostgreSQL, nginx）
- 已验证 API 层基本框架

**可视化原型（两份）：**
- `AgentHub.html`（根目录）—— 高保真视觉原型，3 主题 + Tweaks 面板 + gradient 头像
- `AgentHub-v0.html`（根目录） + `v0/` 子目录 —— 功能更完整，Tailwind + shadcn 风格

**决策：** 以 **v0 原型**为 UX 参考架构，在现有 Vite + React + TS 脚手架上重建。

## 二、分支策略

```
main                 ← 稳定分支，只能从 feat-* 合并
  ├── feat-layout    ← Phase 1: 三栏布局 + 设计基座
  ├── feat-chat      ← Phase 2: 聊天 UI 升级
  ├── feat-tasks     ← Phase 3: 任务管理看板
  ├── feat-groups    ← Phase 4: 群组 + 协调者
  ├── feat-views     ← Phase 5: 次要视图（日历/活动/收件箱/Agent 详情）
  └── feat-agent-crud← Phase 6: Agent 创建与编辑
```

流程：

```bash
# 开始一个功能
scripts/feat-start.bat layout

# 开发完成后
scripts/feat-complete.bat layout

# 代码审查
scripts/code-review.bat feat-layout
```
