# AI Agent 记忆系统对比分析报告

> 本文档对比分析 GitHub 上高星 AI Agent 记忆系统的实现方案，包括 cc-haha、AgentMemory、Claude-Mem、Hindsight 等项目。

---

## 一、项目概览

### 1.1 参评项目

| 项目 | GitHub | Stars | 语言 | 定位 |
|------|--------|-------|------|------|
| **cc-haha** | NanmiCoder/cc-haha | 1.7k+ | TypeScript | Claude Code Desktop 集成 |
| **AgentMemory** | rohitg00/agentmemory | 16.2k | TypeScript | 通用编程 Agent 记忆层 |
| **Claude-Mem** | thedotmack/claude-mem | 17k+ | TypeScript | Claude Code 专用记忆压缩 |
| **Hindsight** | GitHub_Trending/hindsight2 | 2k+ | Python | 仿生三层记忆结构 |
| **Agentic RAG** | 多仓库 | 5k+ | Python | Multi-Agent + RAG |

### 1.2 核心问题

> **当前 AI 编程 Agent 的根本缺陷**：每次会话结束后会遗忘一切。

各项目针对这一问题的解决方案各有特色。

### 5.3 AgentMemory 的数据库 Schema

```sql
-- 观察记录表
CREATE TABLE observations (
  id TEXT PRIMARY KEY,
  content TEXT NOT NULL,
  confidence REAL DEFAULT 0.5,
  tags TEXT[],           -- JSON 数组
  created_at TIMESTAMP,
  session_id TEXT,
  agent_id TEXT,
  source_hook TEXT        -- 来自哪个 hook
);

-- 知识图谱表
CREATE TABLE knowledge_graph (
  subject TEXT,
  predicate TEXT,
  object TEXT,
  weight REAL,
  UNIQUE(subject, predicate, object)
);

-- 向量索引 (使用 SQLite FTS5)
CREATE VIRTUAL TABLE observations_fts USING fts5(
  content,
  content='observations',
  content_rowid='rowid'
);
```

### 9.3 关键实现要点

1. **自动化捕获**：优先实现自动 Hooks，减少用户手动标记负担
2. **混合检索**：结合关键词、向量和知识图谱，提升召回率
3. **渐进式披露**：按需加载，控制 Token 消耗
4. **防重复机制**：避免同一记忆重复注入
5. **可版本控制**：支持将记忆提交到 Git，便于团队共享
