## 关键决策
| 决策 | 原因 | 影响 |
|------|------|------|
| Task 用 status 字段（非原型的 state） | 与 §1.1 类型定义一致，避免和聊天 stage 的 state 混淆 | mock tasks 用 status |
| 拖拽用原生 HTML5 DnD | 无需引第三方库，满足看板移动 | dragOver 高亮 + onDrop 改状态 |
| 看板入口双通道 | 左导航「任务」整屏 + 中心区「任务」Tab | 两处都渲染 TasksTabView |
| Pill 提到模块级组件 | react-hooks v7 static-components 规则禁止 render 内定义组件 | 通过 props 传 open/select |
