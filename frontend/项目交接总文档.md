## 一、项目概况

### 1.1 是什么

IM 聊天式多 Agent 协作平台。用户创建 Agent、拉群、像飞书一样 @Agent 下达任务，协调者自动分解、分派、合并结果。

### 1.2 技术栈

| 层 | 选型 | 版本 |
|----|------|------|
| 框架 | React | 19 |
| 语言 | TypeScript | 6（strict mode） |
| 构建 | Vite | 8 |
| 样式 | Tailwind CSS | 4 |
| 状态管理 | Zustand | 5 |
| 图标 | lucide-react | — |
| UI 基件 | 自实现 shadcn 风格 | 12 个组件 |
| 后端对接 | FastAPI + WebSocket | — |

### 1.3 架构分层

```
L5 Presentation  前端（本仓库）
L4 API Gateway   FastAPI Routers / WS Handlers（后端）
L3 Application   Service 用例编排（后端）
L2 Domain        实体 + Task Engine（后端）
L1 Infrastructure PG / Redis / LLM Adapter（后端）
```

前端只通过 REST + WebSocket 与 L4 通信。

## 三、快速开始

### 3.1 本地开发

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173
npm run build        # tsc -b && vite build → dist/
npm run lint         # eslint
npm run format       # prettier --write
```

### 3.2 容器部署

```bash
docker compose -f ../docker/docker-compose.yml up -d --build frontend
# → http://localhost:5173
```

### 3.3 验收门禁

每次改完跑：

```bash
npx tsc -b            # 零错误（红线 CR-07）
npx eslint .          # 零警告
npm run format:check  # 格式一致
npm run build         # 构建通过
```

## 六、关键设计决策

### 6.1 Mock Seam 策略

所有"假"数据集中在一处，便于替换：

```typescript
// groupStore.ts
// ═══════════════════════════════════════════════
// MOCK SEAM — 假群聊的全部"智能"都在这里。
// 真实接入时：删掉 simulateGroupReply，sendGroup 改为 POST/WS
// ═══════════════════════════════════════════════
export function simulateGroupReply(group: Group, text: string): GroupMessage { ... }
```

### 6.2 后接优先（API Fallback）

```typescript
// agentStore.ts 的标准模式
createAgent: async (input) => {
  try {
    const created = await agentsApi.create(...)  // 调后端
    return created.id
  } catch {
    const id = uid('ag')                         // 降级 mock
    return id
  }
}
```

### 6.3 三套主题

- `:root` — 浅色（暖奶油 + 珊瑚）
- `.dark` — 深色
- `.dim` — 柔暗色
- 通过 `lib/theme.ts applyTweaks()` 切换

### 6.4 设计红线

- CR-07: TypeScript strict mode，禁 `any`
- CR-09: 组件 <200 行
- CR-11: 禁 `console.log`
- API Key 前端不透传明文
