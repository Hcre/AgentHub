## 关键决策

| 决策 | 原因 |
|------|------|
| 不抽 CALLS，只抽 IMPORTS | Python 无类型推断时按裸函数名解析调用产生大量假边——首跑就误报 17 跨层违规 + 7 循环，全是 CALLS-only 假阳（同名方法误归因到 agent_service）。IMPORTS 静态精确，也正是 import-linter / AR-01 的判据 |
| 死代码排除包节点（__init__）| 包命名空间是聚合器、不按名 import，会刷一堆假阳（app.domain.entities 等）。排除后只剩 1 个真信号 |
| stdlib ast 不装重型工具 | 项目 13k 行 < 5万行门槛，装图数据库/graphviz 属过度设计；规范 §五「<5万行用 SQLite/NetworkX」 |
