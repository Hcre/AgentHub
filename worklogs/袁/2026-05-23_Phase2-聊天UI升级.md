## 关键决策
| 决策 | 原因 | 影响 |
|------|------|------|
| 模拟回复用 store 内 setTimeout | mock 阶段无后端，1.1s 延迟还原打字→回复 | Phase 7 换 WS 流式时替换此段 |
| stages/outputs 按 convKey 存 | §2.5 要求按会话绑定 | 切会话右栏自动联动，仅 editor:c2 有种子数据 |
| Composer 工具栏写成显式按钮 | react-hooks v7 refs 规则对 map 内引用 ref 的闭包报错 | 略冗长但合规，且更易读 |
| 消息左对齐（agent/user 同侧） | 对齐原型 Message 设计 | 与 IM 习惯一致，AI Badge 区分角色 |
