## 关键决策
| 决策 | 原因 | 影响 |
|------|------|------|
| 新前端用 nginx 静态托管而非 Vite | v0 原型是 CDN 加载 React + 浏览器内 Babel 编译 jsx，无构建步骤 | Dockerfile 从 node 镜像改为 nginx:alpine，体积更小、无需 npm install |
| nginx index 指向 `AgentHub-v0.html` | 原型入口文件名非 `index.html` | nginx.conf 自定义 `index` + `try_files` fallback |
| frontend 服务去掉 backend 依赖 | 原型用纯 mock 数据（data.js/data-extra.js），不调 /api | 可独立启动，不必先起后端 |
| 端口映射 `5173:80` | 容器内 nginx 监听 80，对外保持原 5173 不变 | 访问地址不变，文档/团队习惯无需调整 |

## 给下一位的交接
> 现在 `frontend/` 已是 v0 静态原型，`docker compose up -d frontend` 即可访问 http://localhost:5173 。
> 这是**纯前端展示原型**，不连后端、数据全是 mock。下一步若要做真实功能，需要决定：是基于此原型补 API 对接逻辑，还是把原型设计落到一个新的正式工程里。
> 注意 nginx.conf 没有配 backend 反向代理（生产用的反代配置在 `docker/nginx/nginx.conf`，本服务未使用）。
