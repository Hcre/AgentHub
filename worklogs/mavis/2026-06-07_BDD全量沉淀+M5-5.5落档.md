| 决策 | 原因 | 影响 |
|------|------|------|
| BDD 集中在 04-commands §六（一处权威）| 跨 spec 散落会重复 + 维护成本高 + 实现者「找 BDD」路径长 | 17 场景单一权威 + §七 映射表 |

| 5 commit 拆分（docs/specs 单独）| per CLAUDE.md 行为准则 + 03-git PR-03 | 1 commit 1 主题 |
| 直接 push main 不走 PR 流程 | user preference（2026-06-07 落档 memory）| pre-push hook 自动跑 check_docs + check_worklog |
