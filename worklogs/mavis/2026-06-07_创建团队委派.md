```
L5 Presentation (紫)  → ChatView / AgentPanel / TaskBoard / Inbox / McpMarket / Settings

L3 Application (绿)   → AgentService / GroupService / ChatService / TaskService / CoordinatorService / Mcp*Service
L2 Domain (黄)        → Aggregates (5) / TaskEngine / TaskFSM / UnifiedAgent ABC / MCP Domain
L1 Infrastructure (红)→ PostgreSQL / Redis / LLMAdapter (3) / AgentRuntime (4) / WS Bridge
```

**关键可视化元素**：
- 颜色梯度：L5 紫 → L4 蓝 → L3 绿 → L2 黄 → L1 红（5 层区分）
- **跨层通信**：
  - 灰色实线箭头（Command 下行，HTTP/WS 请求）L5→L4→L3→L2
  - 青色虚线箭头（Domain Event 上行，Redis Pub/Sub）L1→L2
  - 依赖倒置标注：L1 实现 L2 接口
- **架构红线 AR-01~06** 速查框（5 层依赖 / 只加 Adapter / Harness 无 LLM / Agent 不直通 / FSM 事件溯源 / system-model 解耦）
