### 1. `.github/workflows/ci.yml`（3 jobs + 1 汇总 = 4 jobs / 27 steps）

| Job | 步骤 | 缓存 | Artifact | 期望耗时 |
|-----|------|------|----------|---------|
| `backend` | checkout → setup-python → pip cache → install → ruff lint → ruff format → mypy → pytest (cov) → coverage upload | `~/.cache/pip` keyed by requirements+pyproject | `coverage-backend` (xml) | < 6 min |
| `frontend` | checkout → setup-node → npm ci → tsc -b → eslint → prettier → vitest --coverage → vite build → dist upload | npm (setup-node 内置) keyed by package-lock | `frontend-dist` | < 8 min |
| `e2e` | checkout → setup-node → npm ci → playwright install --with-deps chromium → vite build → vite preview (4173) 等待就绪 → screenshot_p0_p1.cjs → upload screenshot | npm (setup-node 内置) | `playwright-screenshots` | < 4 min |
| `ci-status` | needs all 3 + if:always → 汇总 result 到 GITHUB_STEP_SUMMARY | — | — | < 10 s |

**关键设计决策**：
- `concurrency: ci-${{ github.ref }}` 同 PR 后续 push 自动取消旧 run
- 单 job timeout 15 min（per 工程深度要求）
- backend job 显式注入 SECRET_KEY / DATABASE_URL / LLM_ADAPTER_MODE / ENV（与 `tests/conftest.py` 一致）
- e2e screenshot 失败为 `::warning::`，不阻塞 CI（避免 flaky 阻塞主流程）
- ci-status job 写 GITHUB_STEP_SUMMARY，对接 GitHub UI 红/绿

## 关键决策

| 决策 | 原因 | 影响 |
|------|------|------|
| 3 jobs 分拆（backend/frontend/e2e） + ci-status 汇总 | 单 PR 总时长 ~ 18 min，e2e 靠 `needs` 触发可省 GPU/IO 资源；汇总 job 写 GITHUB_STEP_SUMMARY 给 branch protection 当 required check | 失败定位更清晰（哪个 job 挂） |
| e2e screenshot 失败不阻塞 | 截图脚本历史 flaky，CI 阻塞主线得不偿失；artifact 上传 14 天保留供事后排查 | 视觉回归用 artifact 兜底 |
| cache key 不含 git ref | 跨 PR 复用 cache 提升命中率；只 hash 锁文件 | 依赖未变时 install 步 0s |
| backend env 显式注入 SECRET_KEY / DATABASE_URL | 避免 GitHub Actions 默认 env 触发 `tests/conftest.py` 的硬编码兜底；保证 CI env 一致 | 测试可重复 |
| CODEOWNERS 用 `@Hcre/<agent-name>` | GitHub team 模式，与 `.harness/reins/` 一致 | 自动指派 reviewer |
| CONTRIBUTING.md 不重复 03-git 全文 | 03-git 是权威，CONTRIBUTING 是 5 分钟入口 | 单一权威，避免双源冲突 |
| ci-status.md 单独建文件（非嵌 README） | CI 工程师手册增长快（cache 策略、故障排查、扩展计划），独立成文件利于维护 | 文档聚焦 |
| 单 commit 而非 6 commit | per user preference 2026-06-07 落档 "直推 main" | commit message 必含所有变更 |
| **未配置 branch protection** | GitHub 权限限制 + branch protection 需要 Settings → Branches UI 配，token 无 admin 权限（`permissions: { admin: false }`）；已写推荐配置到 ci-status §九 供 owner 操作 | CI 仍跑（on push/PR），但未强制 required check |
