## 1. 决策：cherry-pick 单 feat commit，不 merge 整 branch

对比两种策略：
- **A. merge 整 branch**：`git merge feature/t4-f1-s1-suggestion`
  - 拖入 14 commit：3 feat + 11 orchestrator state/merge/ADR/docs
  - 拖入的 ADR-0015/docs 是 main 已有的等价 commit → 大量 commit 重复
  - 噪音大
- **B. cherry-pick 单 feat commit**：`git cherry-pick 0e33fa1 0fb1560 81d37c0`
  - 每个 feat commit = 1 file 主改 + 1 test + 1 spec（小颗粒）
  - 不污染 main 进度
  - 保留「commit-per-task」规范

**选 B**。3 feat commit 总改动：t1 改 3 行 + 120 行 test + 17 行 spec / t2 改 47 行 + 103 行 test + 18 行 spec / t4 改 48 行 + 79 行 test + 19 行 spec。
